# Security Policy

IR Lab is an educational/experimental IR framework, currently maintained by one
person. It's not intended for production or security-sensitive deployments, but
if you find a real security issue (e.g. in the dataset download/verification
scripts, or in how untrusted input is processed), please report it responsibly.

## Reporting a vulnerability

Email omar.bounawara.py@gmail.com with details and, if possible, reproduction
steps. Please don't open a public issue for security reports.

As a small, currently solo-maintained project there's no formal SLA, but reports
will be acknowledged and looked at as soon as reasonably possible.

## Supported versions

This project has no stable releases yet (pre-1.0) -- only the latest state of
`main` is supported.
